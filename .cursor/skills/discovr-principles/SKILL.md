# discovr principles

## Before you decide

1. Read the full set in [reference.md](reference.md).
2. Test the choice against **Opinionated / Sociable / Straight**.
3. If still open, find the principle that rules one option out.
4. If none does, pick — no brand theatre. Done when the choice names which principle (or adjective) it obeys.

## The six (short)

1. **Eight things, not eight hundred** — shortlist with reasons; not a catalogue.
2. **We've been to everything on the list** — real verdict on every listing; growth = visit speed.
3. **The first price is the price** — all-in from the feed card; PriceBreakdown = BookingBar.
4. **Never manufacture urgency** — spots-left only when real and under five.
5. **Speak like someone who lives here** — plain Indian English, real places and times.
6. **Boring beats clever when money is involved** — dull copy/layout in pay, cancel, tickets.

## Hard stops

- No listing without a one-line verdict from someone who went.
- No Checked badge while everything is checked.
- Do not add unchecked inventory before changing the positioning sentence.
