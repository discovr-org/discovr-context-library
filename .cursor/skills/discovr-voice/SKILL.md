# discovr voice

## Before you write a string

1. Read [reference.md](reference.md) — especially canonical strings and the three-way comparison.
2. Stance: friend who lives in Goa, has opinions, slightly amused by tourists. Stake in you going out; no stake in which pick.
3. Run the brochure / startup / ours test. If it sounds like the first two, rewrite.
4. Done when every word is a fact someone can act on (or a earned verdict), sentence case, contractions on.

## Hard rules

- Say the thing, then stop. Specific over evocative.
- Contractions always. Sentence case always. Caps only via caption style, never typed.
- Address as "you" — never traveller / explorer / wanderer / nomad.
- Zero emoji in the interface.
- Every listing: one verdict sentence that could not apply to any other listing.
- Indian digit grouping (`₹1,400`). Times as `6:30pm`.
- Buttons name the outcome (`Book 6:30pm`), not the mechanism (`Continue`).
- Money errors: what happened → whether money moved → what to do next.
- Avoid: curated, hidden gem, unforgettable, bucket list, immersive, authentic, vibes, elevate, unlock.

## Where personality stops

Discovery gets the voice. Checkout, cancellation, and tickets get duller on purpose.
